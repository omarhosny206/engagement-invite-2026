# Engagement invitation

موقع عربي بسيط يعمل مباشرة على GitHub Pages، بلا بناء أو حزم إضافية.

## الملفات

- `index.html`: محتوى الدعوة وتفاصيل المكان والتاريخ.
- `style.css`: التصميم والحركة والتجاوب مع الشاشات.
- `script.js`: فتح الظرف ومشاركة الرابط.
- `floral.svg`: الرسمة الزهرية.
- `us.jpeg`: صورتنا وإحنا صغيرين.

يمكن فتح `index.html` مباشرة لمعاينة الدعوة. تم استبعاد صورتَي المرجع من Git عبر `.gitignore`.

للنشر على GitHub Pages: اختر الفرع `main` والمجلد `/ (root)` من إعدادات Pages بعد رفع الملفات.
